# The shared wire-contract schemas (shared/schemas/), imported throughout this
# service -- e.g. `from shared.schemas.commands import Command` in
# realtime/mqtt_client.py and control/router.py.
#
# This was previously undeclared and worked only because `shared/` happens to be
# resolvable on sys.path when running from the repo's parent directory. That
# breaks the moment this service is containerised or deployed anywhere the root
# repo isn't checked out as a sibling -- with an ImportError at startup, not a
# clear dependency error.
#
# shared/ is its own repo as of 2026-08-11: github.com/dgholmes/roverhub-shared
# It's cloned as a sibling of this one (see the root repo's .gitignore), so the
# relative editable install below is unchanged by that extraction.
#
# A relative path rather than the git URL because editable-from-sibling is what
# makes a local schema edit take effect immediately in both services -- valuable
# while the schema surface is still being designed. For a container or any host
# without the sibling checkout, use the URL form instead and pin it:
#
#     pip install "roverhub-shared @ git+https://github.com/dgholmes/roverhub-shared.git@<tag-or-sha>"
#
# Note that repo is private, so a URL install needs a PAT or SSH deploy key.
#
# NOTE: this path is resolved against pip's working directory, not this file's
# location, so `pip install -r requirements.txt` must be run from
# roverhub-backend/. That's already the convention for every component here.
-e ../shared

# IANA timezone database for the stdlib `zoneinfo`, used by tasks/scheduler.py to
# turn a schedule's wall-clock time + zone name ("Asia/Seoul") into a UTC instant.
# Linux and macOS ship that database; Windows does not, and without this package
# every ZoneInfo(...) call raises ZoneInfoNotFoundError -- on the Windows dev
# machine, even ZoneInfo("UTC"). Data only, no code. Schedules store an IANA name
# rather than an offset precisely so a 09:00 patrol survives a DST change, so
# there is no offset-based way around needing it.
tzdata>=2024.1
